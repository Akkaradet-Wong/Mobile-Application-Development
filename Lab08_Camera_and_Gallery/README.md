# Lab 08: Camera & Gallery Saver App

> แอปพลิเคชันเชื่อมต่อฮาร์ดแวร์กล้องถ่ายภาพบนอุปกรณ์เคลื่อนที่ พร้อมฟังก์ชันเปิดหน้าจอกล้อง ถ่ายภาพ สั่นเตือนผ่าน HapticFeedback และบันทึกภาพลงเครื่อง


---

### ฟีเจอร์หลัก (Key Features)
- Camera controller and preview stream
- Capture & save to device album with gallery_saver
- Haptic tactile feedback on snap

---

### วิธีการทดสอบและรัน (How to Run)
```bash
flutter pub get
flutter run
```
