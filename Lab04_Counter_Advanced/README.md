# Lab 04: Advanced Counter (3 Actions)

> แอปพลิเคชัน Counter ขั้นสูงที่มาพร้อม 3 ฟังก์ชันการทำงาน (เพิ่มค่า, ลดค่า, และรีเซ็ตค่าเป็นศูนย์) พร้อมธีมสีแบบ Dynamic Seed Color ใน Material 3


---

### ฟีเจอร์หลัก (Key Features)
- Multi FloatingActionButtons in Row
- Reset counter state
- Material 3 Seed Color Scheme

---

### วิธีการทดสอบและรัน (How to Run)
```bash
flutter pub get
flutter run
```
