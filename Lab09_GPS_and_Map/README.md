# Lab 09: GPS Location & OpenStreetMap Tracker

> แอปพลิเคชันระบุตำแหน่งพิกัดดาวเทียม GPS แบบเรียลไทม์ผ่าน geolocator และเรนเดอร์แผนที่ OpenStreetMap แบบโต้ตอบได้ด้วย flutter_map


---

### ฟีเจอร์หลัก (Key Features)
- Live GPS coordinates querying with geolocator
- Interactive OpenStreetMap rendering via flutter_map
- Custom location pin marker

---

### วิธีการทดสอบและรัน (How to Run)
```bash
flutter pub get
flutter run
```
